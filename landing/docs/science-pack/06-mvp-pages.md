- `concepts/interoception` — 2026-10-05 (phase 2, roadmap #11; written by Claude Code under the same pack). - `evidence/meditation-autonomic-nervous-system` — 2026-10-06 (phase 2; written by Claude Code under the same pack). Evidence synthesis of meditation and autonomic signals — HRV during a session and after a course, resting heart rate, blood pressure (AHA statements: Brook et al. 2013, Levine et al. 2017), cortisol, sleep with autonomic measures — by practice type, with the slow-breathing confound and session-vs-trait limits. New fact study.pascoe2017.trials. Brain changes are left to the meditation cluster articles.
- `measurements/respiratory-rate` — 2026-10-06 (phase 2; written by Claude Code under the same pack). Canonical metric page for resting and sleeping respiratory rate: norms via breath.adult.normal, measurement (manual counting errors, ECG/PPG estimation, thin wearable validation), factors, clinical deterioration sign (early-warning score components not listed), nightly trend in wearable studies (emerging, single studies, COI noted), link to RSA/HRV, when to see a doctor. No new facts.
- `mechanisms/heart-brain-interaction` — 2026-10-06 (phase 2, last page of the plan; written by Claude Code under the same pack). Two-way heart–brain signalling, heartbeat-evoked potentials and cardiac-cycle effects (preliminary), neurovisceral integration as a MODEL with weak correlations (no coefficients), intrinsic cardiac nervous system and heart-field claims as two myth-debunk paragraphs, HeartMath COI notes, takotsubo and stroke–heart syndrome. No new facts.
- `concepts/coherence` — 2026-10-06 (phase 2; written by Claude Code under the same pack). Coherence as the shape of heart-rate oscillation (one dominant slow peak) vs HRV as its size; scoring in words; resonance origin linked, not repeated; HeartMath origin with COI notes; three myth-debunks (autonomic balance, heart–brain phase lock, heart field on others); feedback metric, not a biomarker; ONDA = Apple Watch only.
- `concepts/polyvagal-theory` — 2026-10-06 (phase 2; written by Claude Code under the same pack). The theory in Porges' words (three states, neuroception, dissolution), why it is popular, what agrees with physiology, specific critique (evolution, RSA as vagal readout, dorsal vagus and freezing, neuroception not measurable) with Porges' 2026 reply; therapies: small evidence, largely from the author's group; three myth-debunks; ONDA does not measure polyvagal states.
- `concepts/baroreflex` — 2026-10-06 (phase 2; written by Claude Code under the same pack). Sensors, beat-to-beat loop, BRS (needs blood pressure; methods; age and BP as main correlates; LF reflects baroreflex modulation), resonance and the RSA-generation debate linked, training (one session = short-term; one RCT of biofeedback), orthostatic hypotension with doctor advice; two myth-debunks; ONDA does not measure BP or BRS. Fitness deliberately omitted (no review source).
- `evidence/cold-exposure` — 2026-10-06 (phase 2; written by Claude Code under the same pack). Exposure types kept apart; cold shock vs diving response (autonomic conflict as hypothesis); HRV rises only during exposure; outcomes with classes (stress/sleep, sickness absence not illness days, soreness vs blunted strength gains, brown fat/insulin from mild cold air, Kox = combined techniques); Šrámek dopamine figures with conditions (facts study.sramek2000.*); safety section; two myth-debunks. Shared ColdSafetyBlock on all cold-plunge reviews/round-up/duels + 3 cold-protocol articles.
- `evidence/nasal-breathing` — 2026-10-07 (phase 2; written by Claude Code under the same pack). Nose vs mouth physiology (conditioning, filtering, resistance; sinus nitric oxide with effect size not established); outcomes with classes (sleep/nasal obstruction, Zelano as few epilepsy patients, one small HRV study, no exercise performance change, breathing exercises/Buteyko as add-on for asthma); mouth taping: few small uncontrolled studies, mostly mild apnea, real risks; safety section; two myth-debunks. Shared MouthTapeSafetyBlock (tape and dilator variants) on all breathing-aid reviews/round-up/duels.
- `concepts/cortisol-and-stress-response` — 2026-10-07 (phase 2; written by Claude Code under the same pack). What cortisol does, the HPA axis, the daily rhythm and cortisol awakening response, acute vs chronic stress, how cortisol is actually measured (blood/saliva/urine, timing; Nieman 2008, Bornstein 2016), what breathing and meditation do and do not show (Pascoe 2017, Koncz 2021, Ma 2017), cold exposure (Šrámek 2000). ONDA does not measure cortisol; HRV is not a cortisol reading. Three myth-debunks (adrenal fatigue — Cadegiani 2016; cortisol detox/cortisol face; HRV = cortisol). Site-wide cortisol claims audit fixed in the same change (D:_ONDA_Sciense_cortisol_claims.md).
- `evidence/fast-breathing` — 2026-10-07 (phase 2; written by Claude Code under the same pack). Wim Hof breathing, cyclic hyperventilation, holotropic breathwork, tummo kept apart (bhastrika/kapalabhati left to the pranayama articles); physiology (hypocapnia and alkalosis, brain vessel narrowing — Willie 2014, tingling/calcium debated, adrenaline rise, SpO2 falls during holds, delayed breaking point); outcomes with classes (endotoxin response Kox 2014/Zwaag 2022 = lab model in healthy men, mood mixed, no sprint benefit, tummo temperature, holotropic = hypothesis); safety section first-class (never in water — Boyd 2015, Pernett 2023, Lindholm 2009; epilepsy — Rao 2024); three myth-debunks (oxygenation, alkaline blood cures disease, proven for autoimmune disease). New facts study.kox2014.groups, study.zwaag2022.participants, study.citherlet2021.spo2, study.almahayni2024.trials (approved by Yakiv 2026-10-07).
- `evidence/red-light-therapy` — 2026-10-08 (phase 2; written by Claude Code under the same pack). Photobiomodulation vs surgical lasers vs ordinary lamps; mechanism as model (cytochrome c oxidase, nitric oxide hypothesis — Hamblin 2018); dose parameters and biphasic response (Huang 2009), home dose rarely matches trial dose (Cronshaw 2025, Grimes 2025); outcomes with classes (oral mucositis prevention = MASCC/ISOO guideline, knee OA/neck pain/male hair loss = context-dependent with clinical lasers, exercise/skin/cognition = emerging, testosterone/fat loss/mitochondrial health = unknown); FDA clearance explained; safety section (eyes, near-infrared invisible); two myth-debunks (more powerful panel, Alzheimer cure). New facts study.stausholm2019.trials, study.chow2009.trials, study.grimes2025.sponsored, study.lee2023.studies (approved by Yakiv 2026-10-08).
- `evidence/sauna-heat-exposure` — 2026-10-08 (phase 2; written by Claude Code under the same pack). Finnish sauna vs infrared vs hot-water immersion vs clinical heat therapy kept apart; acute physiology (Ketelhut 2019, Lee 2018); KIHD cohort associations (Laukkanen 2015/2017, Zaccardi 2017) always framed as one Finnish cohort of men 42–60, association not causation, frequent users healthier overall; small trials (Brunt 2016, Atencio 2025, Källström 2018, Tei 2016, Janssen 2016, Ahokas 2023); detox framed as not shown (Sears 2012), longevity myth-debunk; safety (alcohol — Kenttämies 2008, Hannuksela 2001; pregnancy — Moretti 2005).
- `evidence/eeg-neurofeedback` — 2026-10-08 (phase 2; written by Claude Code under the same pack). Clinical neurofeedback vs consumer EEG headsets vs fNIRS (Mendi) kept apart; what headsets record (Krigolson 2017) and artefacts (Ratti 2017); focus/calm scores = proprietary formulas, not validated; ADHD blinded/sham evidence (Cortese 2016, Westwood 2025, NCG 2021) with Bussalb 2019 always framed as the reading of industry-linked authors (Mensia Technologies) next to the independent data; insomnia real = sham (Schabus 2017, Recio-Rodriguez 2024); depression emerging (Fernández-Álvarez 2022); anxiety unknown; sham section, EEG vs HRV biofeedback, safety (brain-data privacy as general caution), conflicts of interest; one myth-debunk (ADHD). New facts study.cortese2016.trials, study.westwood2025.trials, study.nfcg2021.participants, study.schabus2017.design, study.ratti2017.participants (approved by Yakiv 2026-10-08).
- `evidence/pemf` — 2026-10-08 (phase 2; written by Claude Code under the same pack). Medical PEMF and bone stimulators vs consumer mats/wearables vs TMS kept apart; mechanisms as models (Pilla 2013, Kaadan 2024 — maker-employed co-authors); dose parameters and why trials and home devices are hard to compare; outcomes with classes (non-union debated — Griffin 2011 Cochrane vs Aleem 2016 with industry ties; OA/knee OA/chronic low back pain context-dependent, short-term, not better than physiotherapy; post-surgery pain emerging; fibromyalgia BEMER = sham — Multanen 2018; depression two small studies — Martiny 2010, Larsen 2020; microcirculation not shown — Biermann 2020; sleep/energy unknown — uncontrolled manufacturer survey Bohn 2013); regulatory section (bone stimulators approved via PMA until May 2026, class II via 510(k) since 18 May 2026 — Federal Register 91 FR 20352, doc. 2026-07366; nonthermal shortwave; Bemer cleared under NGX; registered vs cleared vs approved); safety (implants first); three claims (cell energy, insomnia/depression therapy, Schumann resonance) stated as "not shown" without myth-debunk markers. New facts study.griffin2011.trials, study.aleem2016.trials, study.yang2020.trials, study.vigano2021.trials, study.sun2022.trials, study.zhang2020.trials, study.multanen2018.participants, study.larsen2020.participants, study.biermann2020.participants, study.bohn2013.questionnaires (approved by Yakiv 2026-10-08).
- `evidence/yoga-nidra-nsdr` — 2026-10-08 (phase 2; written by Claude Code under the same pack). Yoga nidra (Satyananda tradition, iRest) vs NSDR kept apart; awake state on EEG (Datta 2022, Zaccaro 2021); session heart rate/HRV (Markil 2012, Ditto 2006 body scan); dopamine myth-debunk (Kjaer 2002: one small PET study, indirect raclopride estimate, not replicated; participant count not verifiable, page says "a small group"); sleep emerging, very low certainty (Singh 2026, Dutta 2026, Datta 2021/2023); stress/anxiety/depression emerging, likely inflated (Ghai 2026, Moszeik 2025); PTSD mostly uncontrolled iRest studies; BP/HR and pain emerging (better than passive, not active controls); NSDR as short rest and the nap comparison (Boukhris 2024/2026); safety (trauma-informed delivery, Luu 2024); conflicts of interest. - `mechanisms/sleep-and-hrv` — 2026-10-08 (phase 2; written by Claude Code under the same pack). Heart rate and HRV across the night and sleep stages (Trinder 2001, Viola 2002, Boudreau 2013, Stein & Pu 2012); clock vs sleep-stage contribution debated; why the night is a steadier window (Carter 2026); how Oura, Garmin and Apple Health compute nightly values (official pages, HealthKit SDNN; WHOOP not described); wearable sleep staging vs PSG (Chinoy 2021, de Zambotti 2024, manufacturer-run Altini & Kinnunen 2021); sleep apnea heart-rate pattern and sympathetic activity (Guilleminault 1984, Somers 1995), insomnia HRV debated (Dodds 2017), diagnosis per AASM (Kapur 2017); two myth-debunk markers kept. New facts study.chinoy2021.participants, study.trinder2001.participants (approved by Yakiv 2026-10-08). All sources approved 2026-10-08.
- `evidence/humming-and-chanting` — 2026-10-08 (phase 2; written by Claude Code under the same pack). Bhramari, Om, mantra/prayer and choir singing kept apart; nasal nitric oxide during humming (Weitzberg 2002 — the fifteen-fold figure only in the body next to its conditions; Maniscalco 2003a/b, Granqvist 2006, Lundberg 2008), sinus treatment not shown; HRV explained by slow breathing so far (Laborde 2022, Bernardi 2001, Vickhoff 2013); added effect of the hum not shown (Ghati 2021 RCT, Kuppusamy 2018 SR); vagus = larynx anatomy only (Breit 2018); Om fMRI pilot without replication (Kalyani 2011); stress/wellbeing (Álvarez-Pérez 2022, Daykin 2018); two claims (cosmic/healing frequency, humming works the vagus harder) stated as "not shown" without myth-debunk markers. New facts study.weitzberg2002.humming, study.weitzberg2002.participants, study.bernardi2001.participants, study.bernardi2001.rate, study.kalyani2011.participants, study.ghati2021.design, study.kuppusamy2018.studies (approved by Yakiv 2026-10-08). - `mechanisms/exercise-and-hrv` — 2026-10-08 (phase 2; written by Claude Code under the same pack, owner-provided sources). Post-exercise HRV drop and recovery by intensity and fitness (Stanley 2013, existing fact training.recovery.time; metaboreflex/baroreflex model hedged); comparable recording conditions (Carter 2026); HRV-guided vs predefined training — modest submaximal benefit, fewer non-responders, no shown effect on performance or VO2peak (Düking 2021 meta-analysis, emerging); honest boundary — null primary outcome in a small cardiac-rehab RCT (Besnier 2026); not shown: long-term benefit for recreational exercisers, best decision rule; no training-load advice; ONDA = SDNN trend vs own baseline, does not plan training. No myth-debunk markers. New facts study.duking2021.studies, study.duking2021.submaximal, study.besnier2026.design, study.besnier2026.vo2peak (approved 2026-10-08 per owner task). Zhang 2025 athlete-biofeedback not used. Image pending (mechanisms-exercise-and-hrv.jpg).
