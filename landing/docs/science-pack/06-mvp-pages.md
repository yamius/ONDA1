- `mechanisms/hrv-day-to-day` — 2026-10-05 (phase 2, roadmap; written by Claude Code under the same pack). Mechanisms, direction, effect sizes and duration of day-to-day HRV change: normal noise, sleep, alcohol, training, illness, stress, caffeine, late eating, menstrual cycle, circadian rhythm, altitude, dehydration, medicines. New facts hrv.dayToDay.cvLnRmssd, hrv.reliability.timeDomainCv, training.recovery.time.
- `concepts/interoception` — 2026-10-05 (phase 2, roadmap #11; written by Claude Code under the same pack). Definition, accuracy/sensibility/awareness, measurement and its validity problems, insula and predictive models (labelled as models), emotion theories (contested), mental-health associations, training evidence. New fact onda.practice.livePulse. Heart–brain interaction is left to `mechanisms/heart-brain-interaction`.
- `evidence/meditation-autonomic-nervous-system` — 2026-10-06 (phase 2; written by Claude Code under the same pack). Evidence synthesis of meditation and autonomic signals — HRV during a session and after a course, resting heart rate, blood pressure (AHA statements: Brook et al. 2013, Levine et al. 2017), cortisol, sleep with autonomic measures — by practice type, with the slow-breathing confound and session-vs-trait limits. New fact study.pascoe2017.trials. Brain changes are left to the meditation cluster articles.
- `measurements/respiratory-rate` — 2026-10-06 (phase 2; written by Claude Code under the same pack). Canonical metric page for resting and sleeping respiratory rate: norms via breath.adult.normal, measurement (manual counting errors, ECG/PPG estimation, thin wearable validation), factors, clinical deterioration sign (early-warning score components not listed), nightly trend in wearable studies (emerging, single studies, COI noted), link to RSA/HRV, when to see a doctor. No new facts.
- `mechanisms/heart-brain-interaction` — 2026-10-06 (phase 2, last page of the plan; written by Claude Code under the same pack). Two-way heart–brain signalling, heartbeat-evoked potentials and cardiac-cycle effects (preliminary), neurovisceral integration as a MODEL with weak correlations (no coefficients), intrinsic cardiac nervous system and heart-field claims as two myth-debunk paragraphs, HeartMath COI notes, takotsubo and stroke–heart syndrome. No new facts.
- `concepts/coherence` — 2026-10-06 (phase 2; written by Claude Code under the same pack). Coherence as the shape of heart-rate oscillation (one dominant slow peak) vs HRV as its size; scoring in words; resonance origin linked, not repeated; HeartMath origin with COI notes; three myth-debunks (autonomic balance, heart–brain phase lock, heart field on others); feedback metric, not a biomarker; ONDA = Apple Watch only.
- `concepts/polyvagal-theory` — 2026-10-06 (phase 2; written by Claude Code under the same pack). The theory in Porges' words (three states, neuroception, dissolution), why it is popular, what agrees with physiology, specific critique (evolution, RSA as vagal readout, dorsal vagus and freezing, neuroception not measurable) with Porges' 2026 reply; therapies: small evidence, largely from the author's group; three myth-debunks; ONDA does not measure polyvagal states.
- `concepts/baroreflex` — 2026-10-06 (phase 2; written by Claude Code under the same pack). Sensors, beat-to-beat loop, BRS (needs blood pressure; methods; age and BP as main correlates; LF reflects baroreflex modulation), resonance and the RSA-generation debate linked, training (one session = short-term; one RCT of biofeedback), orthostatic hypotension with doctor advice; two myth-debunks; ONDA does not measure BP or BRS. Fitness deliberately omitted (no review source).
- `evidence/cold-exposure` — 2026-10-06 (phase 2; written by Claude Code under the same pack). Exposure types kept apart; cold shock vs diving response (autonomic conflict as hypothesis); HRV rises only during exposure; outcomes with classes (stress/sleep, sickness absence not illness days, soreness vs blunted strength gains, brown fat/insulin from mild cold air, Kox = combined techniques); Šrámek dopamine figures with conditions (facts study.sramek2000.*); safety section; two myth-debunks. Shared ColdSafetyBlock on all cold-plunge reviews/round-up/duels + 3 cold-protocol articles.
- `evidence/nasal-breathing` — 2026-10-07 (phase 2; written by Claude Code under the same pack). Nose vs mouth physiology (conditioning, filtering, resistance; sinus nitric oxide with effect size not established); outcomes with classes (sleep/nasal obstruction, Zelano as few epilepsy patients, one small HRV study, no exercise performance change, breathing exercises/Buteyko as add-on for asthma); mouth taping: few small uncontrolled studies, mostly mild apnea, real risks; safety section; two myth-debunks. Shared MouthTapeSafetyBlock (tape and dilator variants) on all breathing-aid reviews/round-up/duels.
- `concepts/cortisol-and-stress-response` — 2026-10-07 (phase 2; written by Claude Code under the same pack). What cortisol does, the HPA axis, the daily rhythm and cortisol awakening response, acute vs chronic stress, how cortisol is actually measured (blood/saliva/urine, timing; Nieman 2008, Bornstein 2016), what breathing and meditation do and do not show (Pascoe 2017, Koncz 2021, Ma 2017), cold exposure (Šrámek 2000). ONDA does not measure cortisol; HRV is not a cortisol reading. Three myth-debunks (adrenal fatigue — Cadegiani 2016; cortisol detox/cortisol face; HRV = cortisol). Site-wide cortisol claims audit fixed in the same change (D:_ONDA_Sciense_cortisol_claims.md).
- `evidence/fast-breathing` — 2026-10-07 (phase 2; written by Claude Code under the same pack). Wim Hof breathing, cyclic hyperventilation, holotropic breathwork, tummo kept apart (bhastrika/kapalabhati left to the pranayama articles); physiology (hypocapnia and alkalosis, brain vessel narrowing — Willie 2014, tingling/calcium debated, adrenaline rise, SpO2 falls during holds, delayed breaking point); outcomes with classes (endotoxin response Kox 2014/Zwaag 2022 = lab model in healthy men, mood mixed, no sprint benefit, tummo temperature, holotropic = hypothesis); safety section first-class (never in water — Boyd 2015, Pernett 2023, Lindholm 2009; epilepsy — Rao 2024); three myth-debunks (oxygenation, alkaline blood cures disease, proven for autoimmune disease). New facts study.kox2014.groups, study.zwaag2022.participants, study.citherlet2021.spo2, study.almahayni2024.trials (approved by Yakiv 2026-10-07).
- `evidence/red-light-therapy` — 2026-10-08 (phase 2; written by Claude Code under the same pack). Photobiomodulation vs surgical lasers vs ordinary lamps; mechanism as model (cytochrome c oxidase, nitric oxide hypothesis — Hamblin 2018); dose parameters and biphasic response (Huang 2009), home dose rarely matches trial dose (Cronshaw 2025, Grimes 2025); outcomes with classes (oral mucositis prevention = MASCC/ISOO guideline, knee OA/neck pain/male hair loss = context-dependent with clinical lasers, exercise/skin/cognition = emerging, testosterone/fat loss/mitochondrial health = unknown); FDA clearance explained; safety section (eyes, near-infrared invisible); two myth-debunks (more powerful panel, Alzheimer cure). New facts study.stausholm2019.trials, study.chow2009.trials, study.grimes2025.sponsored, study.lee2023.studies (approved by Yakiv 2026-10-08).
- `evidence/sauna-heat-exposure` — 2026-10-08 (phase 2; written by Claude Code under the same pack). Finnish sauna vs infrared vs hot-water immersion vs clinical heat therapy kept apart; acute physiology (Ketelhut 2019, Lee 2018); KIHD cohort associations (Laukkanen 2015/2017, Zaccardi 2017) always framed as one Finnish cohort of men 42–60, association not causation, frequent users healthier overall; small trials (Brunt 2016, Atencio 2025, Källström 2018, Tei 2016, Janssen 2016, Ahokas 2023); detox framed as not shown (Sears 2012), longevity myth-debunk; safety (alcohol — Kenttämies 2008, Hannuksela 2001; pregnancy — Moretti 2005).
- `measurements/onda-method` — 2026-10-06 (written by Claude Code under the same pack; source of truth = app code + facts doc). How ONDA reads, compares and stores data; behaviour new in 1.9.3 (local progress without an account, full HRV window at once, device-only diary) is marked "starting with version 1.9.3". Sources: /measurements and /how-it-works (product documentation); /privacy not cited until legal review; analytics not described until the app fix ships.
