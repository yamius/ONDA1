# Руководство по тестированию Apple Watch автономности

## Быстрый старт

### Предварительные требования

1. ✅ Apple Watch подключены и сопряжены с iPhone
2. ✅ Приложение ONDA установлено на обоих устройствах
3. ✅ Разрешения HealthKit даны на часах
4. ✅ Bluetooth включен

### Базовый тест

1. **Откройте приложение ONDA на iPhone**
2. **Откройте приложение ONDA на Apple Watch**
3. **Запустите практику на iPhone**
4. **Проверьте:**
   - На часах появился экран с пульсом
   - На iPhone отображается пульс в реальном времени
   - Индикатор "Watch connected" активен

## Сценарии тестирования

### Тест 1: Системный диалог микрофона (Основной сценарий)

**Цель:** Убедиться что часы продолжают работать когда iPhone показывает диалог

**Шаги:**
1. Запустите практику с эмоциональным анализом (нужен микрофон)
2. Дождитесь появления пульса на часах (2-5 секунд)
3. На iPhone появится системный запрос разрешения на микрофон
4. **НЕ закрывайте диалог** - подождите 10-15 секунд
5. Посмотрите на часы

**Ожидаемый результат:**
- ✅ Часы продолжают показывать пульс
- ✅ Workout сессия активна (зеленый индикатор)
- ✅ После закрытия диалога данные синхронизируются с iPhone

**Логи для проверки:**
```
[WorkoutManager] 💗 HR: 78 bpm (reachable: false)
[WorkoutManager] 📦 HR queued via transferUserInfo: 78 bpm
[WorkoutManager] 📋 Application context updated
[WorkoutManager] 📡 Reachability changed: true
[WorkoutManager] 💗 Connection restored, sending current HR: 79 bpm
```

---

### Тест 2: iPhone в фоновом режиме

**Цель:** Проверить работу когда iPhone заблокирован

**Шаги:**
1. Запустите практику
2. Дождитесь стабильного пульса (30 секунд)
3. Заблокируйте iPhone (кнопка питания)
4. Ждите 1 минуту, наблюдая за часами
5. Разблокируйте iPhone и откройте приложение

**Ожидаемый результат:**
- ✅ Часы продолжают показывать пульс всё время
- ✅ После разблокировки iPhone показывает актуальный пульс
- ✅ Нет разрыва в данных

---

### Тест 3: Отключение Bluetooth

**Цель:** Проверить автономность часов при потере связи

**Шаги:**
1. Запустите практику
2. Дождитесь стабильного пульса
3. **На iPhone:** Настройки → Bluetooth → Выключить
4. Наблюдайте за часами 30 секунд
5. **На iPhone:** Включите Bluetooth обратно
6. Подождите 5-10 секунд

**Ожидаемый результат:**
- ✅ Часы продолжают показывать пульс при выключенном Bluetooth
- ✅ Extended runtime session держит часы активными
- ✅ После включения Bluetooth связь восстанавливается автоматически
- ✅ Накопленные данные отправляются на iPhone

**Логи:**
```
[WorkoutManager] 📡 Reachability changed: false
[WorkoutManager] 📦 HR queued via transferUserInfo: 80 bpm
... (30 секунд накопления) ...
[WorkoutManager] 📡 Reachability changed: true
[WorkoutManager] 💗 Connection restored, sending current HR: 82 bpm
```

---

### Тест 4: Перезапуск приложения iPhone

**Цель:** Проверить что часы работают независимо

**Шаги:**
1. Запустите практику
2. Дождитесь стабильного пульса
3. **На iPhone:** Смахните приложение вверх (Force Quit)
4. Наблюдайте за часами 30 секунд
5. Откройте приложение ONDA на iPhone снова
6. Проверьте отображение пульса

**Ожидаемый результат:**
- ✅ Часы НЕ прекратили работу
- ✅ Workout сессия продолжается
- ✅ При запуске приложения iPhone получает текущий HR в течение 2-4 секунд

---

### Тест 5: Автоматический перезапуск при ошибке

**Цель:** Проверить восстановление после сбоя

**Шаги:**
1. Запустите практику
2. Дождитесь стабильного пульса
3. **На часах:** Принудительно завершите приложение (долгое нажатие боковой кнопки + выключить)
4. Откройте приложение на часах снова
5. Подождите 5 секунд

**Ожидаемый результат:**
- ✅ Приложение автоматически возобновляет workout
- ✅ Связь с iPhone восстанавливается
- ✅ Пульс начинает передаваться снова

## Интерпретация логов

### Позитивные индикаторы (всё работает)

```
✅ WCSession activated
💗 HR: 78 bpm
✅ HR sent successfully
🟢 START command received
✅ Workout started successfully
```

### Нормальные ситуации (не ошибки)

```
📦 HR queued via transferUserInfo    ← iPhone в фоне, используется очередь
📋 Application context updated       ← Обновление контекста для синхронизации
📡 Reachability changed: false       ← Временная потеря связи (нормально)
ℹ️ Workout already running          ← Защита от дублирования
```

### Проблемные ситуации (требуют внимания)

```
❌ WCSession activation failed       ← Проблема с WatchConnectivity
❌ Workout session error             ← Ошибка HealthKit
⚠️ Workout ended unexpectedly        ← Сессия прервалась (будет автоперезапуск)
⚠️ Invalid HR value                  ← Некорректные данные пульса
```

### Автоматическое восстановление

```
🔄 Restarting workout after unexpected end
🔄 Attempting to restart workout after error
💗 Connection restored, sending current HR
📡 Reachability changed: true
```

## Чек-лист для отладки

Если пульс не передается, проверьте по порядку:

### 1. Базовая настройка
- [ ] Apple Watch на руке, экран активен
- [ ] Bluetooth включен на обоих устройствах
- [ ] Приложения установлены на обоих устройствах

### 2. Разрешения
- [ ] HealthKit разрешения даны на часах
- [ ] В приложении на часах показан экран с пульсом (не ошибка разрешений)

### 3. WCSession
- [ ] В логах iPhone: `✅ WCSession activated`
- [ ] В логах Watch: `✅ WCSession activated`
- [ ] `reachable: true` или данные через `transferUserInfo`

### 4. Workout сессия
- [ ] В логах: `✅ Workout started successfully`
- [ ] На часах: зеленый индикатор "Активна"
- [ ] Пульс отображается на часах (локально)

### 5. Передача данных
- [ ] В логах часов: `💗 HR: XX bpm`
- [ ] В логах iPhone: `💗 HR#X: XX bpm`
- [ ] На экране iPhone: значение BPM обновляется

## Метрики производительности

### Нормальные значения:

| Метрика | Нормальное значение | Примечание |
|---------|-------------------|------------|
| Время до первого HR | 3-8 секунд | Зависит от HealthKit |
| Частота обновлений HR | 1-5 секунд | При активной связи |
| Задержка при восстановлении | 2-5 секунд | После потери связи |
| Размер очереди | 0-5 значений | При нормальной работе |
| Расход батареи часов | ~10-15%/час | Во время практики |

### Проблемные значения:

| Метрика | Проблемное значение | Действие |
|---------|-------------------|---------|
| Время до первого HR | >15 секунд | Проверить разрешения HealthKit |
| Частота обновлений HR | >10 секунд | Проверить WCSession reachability |
| Размер очереди | >20 значений | Связь долго не восстанавливается |
| Потеря пакетов | >30% | Проблема с Bluetooth |

## Частые проблемы и решения

### Проблема: "HR не появляется на часах"

**Причина:** Нет разрешений HealthKit

**Решение:**
1. Откройте приложение на часах
2. Нажмите "Разрешить" при запросе HealthKit
3. Перезапустите практику

---

### Проблема: "HR есть на часах, но не на iPhone"

**Причина:** WCSession не активна или не reachable

**Решение:**
1. Проверьте Bluetooth
2. Посмотрите логи: `WCSession activated`
3. Проверьте: `reachable: true` или `📦 transferUserInfo`
4. Если `transferUserInfo` - это нормально, данные придут через 2-10 секунд

---

### Проблема: "Workout останавливается при диалоге"

**Причина:** Старая версия кода (до исправлений)

**Решение:**
1. Убедитесь что используется обновленный `WorkoutManager.swift`
2. Проверьте наличие `Extended runtime session`
3. Перезапустите приложение на часах

---

### Проблема: "Большая задержка данных (>30 секунд)"

**Причина:** Много данных в очереди transferUserInfo

**Решение:**
1. Проверьте размер очереди в логах
2. Перезапустите приложение на iPhone
3. Если проблема повторяется - проверьте Bluetooth соединение
