# Analytics Roadmap

План развития аналитической инфраструктуры ONDA.

---

## Текущий статус

✅ **Реализовано:**
- Таблица `app_events` для сбора событий
- `AnalyticsService` с offline queue
- 17 SQL views для ключевых метрик
- Документация: `docs/guides/analytics-views.md`

---

## План по стадиям

| Стадия | Юзеров | Решение | Стоимость |
|--------|--------|---------|-----------|
| **MVP** | 0-100 | Supabase SQL Editor + сохранённые запросы | Бесплатно |
| **Рост** | 100-1000 | Metabase self-hosted (Railway/Render) | Бесплатно |
| **Масштаб** | 1000+ | PostHog или Amplitude | ~$0-500/мес |

---

## Детали по каждой стадии

### Стадия 1: MVP (сейчас)

**Инструменты:** Supabase SQL Editor

**Ежедневный мониторинг:**
```sql
-- Главные метрики
SELECT * FROM analytics_key_metrics;

-- Практики
SELECT * FROM analytics_practice_funnel LIMIT 7;

-- Ошибки
SELECT * FROM analytics_errors;
```

**Когда переходить дальше:**
- Команда >1 человека смотрит метрики
- Нужны графики для инвесторов/отчётов
- Надоело писать SQL каждый раз

---

### Стадия 2: Рост (100-1000 юзеров)

**Инструмент:** Metabase

**Варианты деплоя:**
1. **Railway** — бесплатный tier, 1 клик деплой
2. **Render** — бесплатный tier
3. **VPS** — $5/мес (DigitalOcean, Hetzner)

**Что даёт:**
- Красивые дашборды без кода
- Автообновление графиков
- Шаринг по ссылке
- Email алерты

**Подключение к Supabase:**
- Host: `db.[project-ref].supabase.co`
- Port: `5432`
- Database: `postgres`
- User/Password: из Supabase Settings → Database

---

### Стадия 3: Масштаб (1000+ юзеров)

**Варианты:**

#### PostHog
- 1M событий/мес бесплатно
- Funnels, Retention, Paths из коробки
- Session recordings
- Feature flags
- Self-hosted вариант

#### Amplitude
- Индустриальный стандарт
- Мощная сегментация
- Дороже, но больше возможностей

**Когда переходить:**
- Нужен A/B тестинг
- Сложные воронки и когорты
- Команда продуктовых аналитиков

---

## Дополнительно: Админка

Для управления юзерами (не только аналитика):

| Инструмент | Для чего | Цена |
|------------|----------|------|
| **Retool** | Админка с действиями (бан, возврат, промокоды) | 5 юзеров бесплатно |
| **Supabase Dashboard** | Простой просмотр таблиц | Бесплатно |

**Идеальная связка:**
- Metabase → графики и метрики
- Retool → админка для поддержки
