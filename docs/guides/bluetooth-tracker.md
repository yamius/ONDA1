# 🔵 Инструкция по подключению Bluetooth пульсометра

> **⚠️ Поправка:** Web Bluetooth **не поддерживается в iOS Safari/WKWebView** — на
> iOS пульс с нагрудных датчиков идёт через Apple Watch/HealthKit, а не через Web
> Bluetooth. Web Bluetooth актуален для Android/десктопного Chrome.

## 🎯 Что это?

В приложении ONDA уже **полностью реализовано** подключение Bluetooth пульсометров через Web Bluetooth API. Вы можете подключить любой совместимый пульсометр и получать **реальные данные о пульсе в режиме реального времени**.

---

## 📱 Как подключить трекер?

### **Шаг 1: Подготовьте трекер**
- Включите ваш Bluetooth пульсометр (Mi Band, Polar, Garmin и т.д.)
- Убедитесь что Bluetooth включен на телефоне
- **Важно:** Трекер должен быть **НЕ подключен** к другим приложениям

### **Шаг 2: Откройте ONDA**
- Запустите приложение ONDA на вашем Android устройстве

### **Шаг 3: Откройте Настройки**
- Нажмите кнопку **⚙️ Settings** (Настройки) в правом верхнем углу экрана

### **Шаг 4: Найдите секцию Bluetooth**
- Прокрутите вниз до раздела с Bluetooth
- Вы увидите кнопку **🔵 "Connect Tracker"** (Подключить Трекер)

### **Шаг 5: Подключите устройство**
1. Нажмите кнопку **"Connect Tracker"**
2. Браузер откроет диалог выбора Bluetooth устройств
3. В списке появятся **все доступные пульсометры** рядом с вами
4. Выберите ваше устройство (например, "Heart Rate Monitor", "Polar H10", "Mi Band")
5. Нажмите **"Pair"** (Подключить) в диалоге

### **Шаг 6: Готово! ✅**
- Кнопка изменится на **✅ "Tracker Connected"** (Трекер подключен)
- Появится кнопка **❌ "Disconnect"** для отключения
- Ниже отобразится панель с **реальными данными**

## 📊 Какие данные вы увидите?

### **Базовые показатели (4 метрики):**

1. **❤️ Heart Rate** (Пульс)
   - Текущий пульс в ударах в минуту (BPM)
   - Обновляется в реальном времени

2. **🌬️ Breathing Rate** (Частота дыхания)
   - Вычисляется автоматически из вариабельности пульса
   - Показывается в вдохах/минуту

3. **⚡ Stress** (Стресс)
   - Уровень стресса от 0 до 100%
   - Основан на отклонении пульса от базового уровня

4. **🔋 Energy** (Энергия)
   - Уровень энергии от 0 до 100%
   - Вычисляется из пульса и активности

### **Расширенные показатели (5 метрик):**

5. **HRV surrogate** (Вариабельность сердечного ритма)
   - Стандартное отклонение пульса
   - Высокое HRV = лучшее здоровье

6. **Cardiac Stability Index** (Индекс стабильности сердца)
   - Показывает стабильность работы сердца
   - Значение от 0 до 1

7. **Recovery Rate** (Скорость восстановления)
   - Как быстро пульс возвращается к норме
   - Положительные значения = восстановление

8. **HR trend slope** (Тренд пульса)
   - Показывает направление изменения пульса
   - Положительный = пульс растет, отрицательный = падает

9. **HR Acceleration** (Ускорение пульса)
   - Скорость изменения пульса
   - Помогает предсказать будущие изменения

### **Эмоциональные состояния (6 индексов):**

10. **Alarm / Anxiety** (Тревожность)
    - Уровень беспокойства и тревоги (0-100)

11. **Relaxation / Calmness** (Спокойствие)
    - Уровень расслабленности (0-100)

12. **Focus / Concentration** (Концентрация)
    - Уровень сосредоточенности (0-100)

13. **Excitement** (Возбуждение)
    - Уровень возбуждения и энтузиазма (0-100)

14. **Fatigue** (Усталость)
    - Уровень усталости (0-100)

15. **Flow** (Состояние потока)
    - Находитесь ли вы в состоянии "потока" (0-100)

## 🧪 Технические детали

### **Как это работает:**

1. **Web Bluetooth API:**
   - Используется стандартный Web Bluetooth API
   - Работает прямо в браузере WebView на Android
   - Не требует установки дополнительных приложений

2. **Heart Rate Service (BLE):**
   - Подключается к стандартному Heart Rate Service (UUID: 0x180D)
   - Читает характеристику Heart Rate Measurement (UUID: 0x2A37)
   - Получает данные в реальном времени через BLE notifications

3. **Обработка данных:**
   - Пульс записывается в буфер (последние 45 секунд)
   - Каждые 2 секунды вычисляются все метрики
   - Используется DSP алгоритмы (Goertzel, EWMA) для анализа

### **Файлы реализации:**

```
src/hooks/useHeartRate.ts         ← Bluetooth подключение
src/hooks/useVitals.ts             ← Вычисление метрик
src/hooks/heartRateStore.ts        ← Хранение данных
src/components/SettingsModal.tsx   ← UI кнопки
```

## ❓ Часто задаваемые вопросы

### **1. Не вижу мое устройство в списке?**
- Убедитесь что Bluetooth включен на телефоне
- Убедитесь что трекер НЕ подключен к другим приложениям
- Попробуйте перезапустить трекер
- Проверьте что трекер находится рядом с телефоном

### **2. Подключение разрывается?**
- Убедитесь что трекер заряжен
- Держите трекер близко к телефону
- Проверьте что другие приложения не используют трекер

### **3. Данные не обновляются?**
- Подождите 10-15 секунд для накопления данных
- Проверьте что трекер измеряет пульс (наденьте его)
- Проверьте логи в браузере (откройте Developer Tools)

### **4. Можно ли использовать два трекера одновременно?**
- Нет, одновременно можно подключить только один BLE пульсометр
- Но вы можете переключаться между трекерами

### **5. Работает ли на iOS?**
- Да, если приложение запущено через Safari или Chrome
- Web Bluetooth API поддерживается в iOS 16+
