# 🚨 СРОЧНОЕ ИСПРАВЛЕНИЕ: Разрешения на часах

## Проблема
Вы дали разрешения на iPhone, но на часах диалог разрешений не появился потому что **используется старая версия кода** (без автоматического запроса разрешений).

---

## ⚡ ВАРИАНТ 1: Быстрое исправление (5 минут)

### Выдайте разрешения на часах ВРУЧНУЮ

#### Способ А: Через UI приложения на часах

1. **Откройте ONDA на Apple Watch**
   - Найдите приложение на часах
   - Запустите его

2. **Должен появиться экран:**
   - Спиннер "Ожидание..." или
   - Кнопка "Разрешить"

3. **Если есть кнопка "Разрешить":**
   - Нажмите на неё
   - Появится системный диалог HealthKit
   - Разрешите чтение пульса

4. **Если только спиннер:**
   - Перейдите к Способу Б

#### Способ Б: Через настройки Watch

1. **На Apple Watch:**
   - Откройте **Настройки**
   - Прокрутите вниз → **Здоровье**
   - Найдите **ONDA**
   - Включите: **Чтение данных о ЧСС** (пульс)

2. **Вернитесь в приложение ONDA на часах**
   - Должен начаться мониторинг пульса

#### Способ В: Через iPhone Watch App

1. **На iPhone:**
   - Откройте приложение **Watch**
   - Прокрутите вниз → найдите **ONDA**
   - Нажмите на приложение
   - **Здоровье** → Включите **Чтение ЧСС**

### ✅ Проверка

После выдачи разрешений:

1. Откройте Debug Monitor на iPhone
2. В панели Watch Diagnostics должно появиться:
   - `Last HR Value: XX bpm`
   - `Total Updates` растет
   - `✅ All systems operational`

### ⚠️ Недостаток этого способа

При следующей переустановке приложения проблема вернется - нужно будет опять выдавать разрешения вручную.

## 🔨 ВАРИАНТ 2: Правильное решение (15 минут)

### Установите обновленную версию кода

Я уже добавил автоматический запрос разрешений в код. Нужно просто пересобрать и установить приложение.

#### Шаг 1: Быстрая пересборка

```bash
cd /workspace
./rebuild-watch.sh
```

Или вручную:

```bash
# 1. Синхронизация
npx cap sync ios

# 2. Открыть Xcode
npx cap open ios
```

#### Шаг 2: В Xcode

**Для iPhone (опционально):**
1. Схема: **App**
2. Destination: **Ваш iPhone**
3. Product → Run (⌘R)

**Для Watch (ОБЯЗАТЕЛЬНО!):**
1. Схема: **OndaWatch Watch App**
2. Destination: **Ваши Apple Watch**
3. Product → Run (⌘R)
4. Ждите 1-2 минуты

#### Шаг 3: Проверка новой версии

1. **Подключите часы к Xcode Console:**
   - Window → Devices and Simulators
   - Выберите ваши Apple Watch
   - Откройте Console

2. **Запустите приложение на iPhone**
   - Пройдите процесс выдачи разрешений
   - Откройте ONDA на часах

3. **В Console часов должно появиться:**
   ```
   [WorkoutManager] 🟢 START command received
   [WorkoutManager] 🔐 HealthKit authorization status: NOT_DETERMINED ⚠️
   [WorkoutManager] ⚠️ HealthKit permission NOT GRANTED - requesting now...
   ```

4. **НА ЧАСАХ ПОЯВИТСЯ ДИАЛОГ РАЗРЕШЕНИЙ АВТОМАТИЧЕСКИ!** ✅

### ✅ Преимущества этого способа

- Разрешения будут запрашиваться автоматически всегда
- Работает для всех новых пользователей
- Не нужно объяснять как выдавать разрешения вручную

## 🐛 Отладка

### Как проверить работает ли Вариант 1 (вручную):

1. **Откройте Debug Monitor на iPhone**
2. **Посмотрите панель "Apple Watch Diagnostics"**

**Если разрешения выданы правильно:**
```
Heart Rate Data:
  Last Value: 75 bpm ✅
  Total Updates: 5 (растет) ✅

Permissions (iPhone):
  HealthKit: ✅
  Microphone: ✅

Quick Diagnostics:
  ✅ All systems operational
```

**Если разрешения НЕ выданы:**
```
Heart Rate Data:
  Last Value: —
  Total Updates: 0

Quick Diagnostics:
  ⚠️ No HR data received yet - check Watch permissions
```

### Как проверить работает ли Вариант 2 (пересборка):

Подключите часы к Xcode Console и посмотрите логи при запуске.

**Старая версия (текущая):**
```

```

**Новая версия (после пересборки):**

## 📞 Если ничего не помогает

1. **Экспортируйте логи из Debug Monitor:**
   - Нажмите кнопку Download
   - Отправьте файл `onda-debug-*.txt`

2. **Сделайте скриншот панели Watch Diagnostics:**
   - Особенно секции:
     - WCSession Status
     - Permissions (iPhone)
     - Quick Diagnostics

3. **Логи с часов (если можете):**
   - Xcode → Window → Devices and Simulators
   - Выберите Apple Watch → Console
   - Скопируйте логи `[WorkoutManager]`
