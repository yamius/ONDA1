# 🚀 Быстрый старт - Debug Monitor + Автоматические разрешения

## ✅ Что сделано

### 1. Улучшен Debug Monitor
- Добавлена панель **Apple Watch Diagnostics** с полной диагностикой связи
- Показывает: WCSession статус, HR данные, разрешения, команды, события
- Добавлены кнопки для быстрого тестирования (START, STOP, STATUS, PING)
- Автоматические подсказки о проблемах

### 2. Автоматический запрос разрешений на часах
- При команде `START` часы АВТОМАТИЧЕСКИ запросят разрешения HealthKit
- При команде `REQUEST_OPEN` тоже проверяются разрешения
- Добавлено детальное логирование статуса разрешений

---

## 🧪 Как протестировать (5 минут)

### Шаг 1: Соберите приложение
```bash
# Для iOS
npx cap sync ios
npx cap open ios
```

### Шаг 2: Запустите на iPhone + Watch
1. Запустите приложение на iPhone
2. Откройте Debug Monitor (кнопка с жуком 🐛 внизу слева)
3. Откройте панель "Apple Watch Diagnostics" (нажмите на заголовок)

### Шаг 3: Выдайте разрешения на iPhone
1. Пройдите экран разрешений
2. Разрешите микрофон
3. В Debug Monitor увидите:
   - `Permissions (iPhone)` → Microphone 🟢
   - В логах: `✅ Watch оповещены`

### Шаг 4: Откройте ONDA на часах
1. Часы завибрируют (получили команду)
2. **ВАЖНО:** Должен появиться диалог разрешений HealthKit! ✅
3. Нажмите "Разрешить"
4. Выдайте разрешения

### Шаг 5: Проверьте данные в Debug Monitor
В панели Watch Diagnostics должно быть:

**WCSession Status:**
- Supported: 🟢
- Paired: 🟢
- App Installed: 🟢
- Reachable: 🟢 (пульсирует)

**Heart Rate Data:**
- Last Value: `78 bpm` (ваш пульс)
- Total Updates: растет

**Permissions (iPhone):**
- HealthKit: 🟢
- Microphone: 🟢

**Quick Diagnostics:**
- `✅ All systems operational`

## 🎯 Что проверить

### ✅ Разрешения на часах появляются автоматически
Если при первом запуске разрешения НЕ появились:
1. В Debug Monitor нажмите кнопку **START**
2. Посмотрите на часы - должен появиться диалог

### ✅ HR данные приходят стабильно
В панели Watch Diagnostics:
- `Last Value` обновляется каждые 1-5 секунд
- `Total Updates` растет
- В логах появляются `💗 HR: XX bpm`

### ✅ Связь восстанавливается автоматически
1. Закройте приложение на часах
2. `Reachable` станет 🟠 оранжевым
3. `Connection Lost Count` +1
4. Откройте приложение на часах снова
5. `Reachable` снова 🟢 зеленый
6. `Connection Restored Count` +1
7. HR данные возобновляются

## 🐛 Если что-то не работает

### Проблема: Разрешения на часах не появляются

**Проверьте логи на часах:**
Подключите часы к Xcode → Console → фильтр `WorkoutManager`

**Должно быть:**
```
[WorkoutManager] 🟢 START command received
[WorkoutManager] 🔐 HealthKit authorization status: NOT_DETERMINED ⚠️
[WorkoutManager] ⚠️ HealthKit permission NOT GRANTED - requesting now...
```

**Если статус `DENIED ❌`:**
- Разрешения были отклонены ранее
- Откройте: Watch → Настройки → Здоровье → ONDA → Разрешить чтение пульса

**Если статус `AUTHORIZED ✅` но пульса нет:**
- Проверьте что часы на руке
- Подождите 10-15 секунд
- Посмотрите в Debug Monitor → Heart Rate Data

---

### Проблема: Watch not reachable

**Решение:**
1. В Debug Monitor нажмите кнопку **📳 REQUEST OPEN**
2. Часы завибрируют 3 раза
3. Откройте приложение ONDA на часах
4. `Reachable` должен стать 🟢

---

### Проблема: No HR data received

**Проверьте в Debug Monitor:**

1. **WCSession Status** - все должно быть 🟢
2. **Permissions** - HealthKit должен быть 🟢
3. **Quick Diagnostics** - посмотрите подсказку

**Частые причины:**
- Часы не на руке (Watch не замеряет пульс)
- Приложение на часах закрыто (нажмите REQUEST OPEN)
- Разрешения не выданы (нажмите START для запроса)

---

## 📋 Отправьте мне логи

Если проблема осталась, экспортируйте логи:

1. В Debug Monitor нажмите кнопку **Download** (стрелка вниз)
2. Логи сохранятся в файл `onda-debug-YYYY-MM-DD-HH-MM-SS.txt`
3. На iOS можно нажать **Share** и отправить мне логи

**Что искать в логах:**
- `[WorkoutManager]` - логи с часов
- `[Permissions]` - процесс выдачи разрешений
- `[Watch]` - события связи
- `💗 HR:` - получение пульса
